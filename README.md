# VDS-Editor-2025

You can open this solution in Visual Studio 2022 (any edition) to edit the Vault Data Standard 2025 default configuration files.
Note - all configuration files are linked to the default installation path.
<img width="919" height="463" alt="image" src="https://github.com/user-attachments/assets/7af2e20d-dfd5-4d17-bda2-d8a934aad6d1" />

The opened solution project should compile without errors (Note: VS 2022 requires compilation to render XAML files).
Please continue editing XAML and script files in this manner. I recommend displaying the document Outline for XAML files.
<img width="1910" height="1147" alt="image" src="https://github.com/user-attachments/assets/b01fbb8e-27ec-4d9d-b8f2-f54f8e859625" />

Please submit any issues in the [Issues section](https://github.com/koechlm/VDS-Editor-2025/issues) of this repository.
Please respect the disclaimer included in the download.

Users migrating legacy configurations can download a step-by-step documentation: https://autode.sk/4l1Znm3.
